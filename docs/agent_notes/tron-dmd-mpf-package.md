DMD format: image count RAM 0x36f4c (=8181), table ptr 0x36f50 -> file 0x125ae8, u32 = bank<<24|offset (bank N = file N*0x800000). Header 13 bytes: u16 rid, u16 group, u32 flags (1 delta, 2 last frame of animation, 4 cache), s16 w, s16 h, u8 format. Formats 0 raw, 1 RLE col-major, 7 RLE row-major (op=b&3: 0 literal,1 zeros,2 0xF run,3 repeat; n=b>>2), 12 packed 4bpp low nibble first, 3/9 delta col/row (signed byte: <0 skip, >0 literal) applied on frame rid-1. Pixel 255 = transparent. Animations 87x32 drawn at x=41. Message strings: table 0x040eeb7c, count 0x040d0da0, fetched by 0xa58c(id).

Capture method: PinMAME (libpinmame) patched with a per-instruction ARM hook (JIT off). Force a deff by hijacking task_sleep entry 0xb91c: set r0=id,r1=0,r2=1, lr=0xb91c, pc=0x280b0, restore regs when sp matches. Draw dispatch 0x2b194/0x2b2a0 (r0 = image record, rid at +0); frame flip 0x27830; current task 0x372c0, deff id at task+0x24; active deff u16 0x381a8. Start a game: trough 18-21 closed, 4 coins (key 5, 1/3 credit each), start key 1, HandleKeyboard=1.
